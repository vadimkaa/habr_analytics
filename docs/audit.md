# Методологические решения и проверки

Документ поясняет исследовательские ограничения, наиболее важные контрольные
проверки и связи с кодом. Результаты и числа в статье формируются из
`data/results/` и `experiments/catboost/results/`.

## Наблюдательные данные

- Просмотры получены единым срезом 9–10 ноября 2026 года. Дата публикации
  статьи не равна дате измерения результата. Разбиение по времени не создаёт
  независимого исторического теста; проверки на данных 2026 года имеют статус
  `audit_exposed`.
- VPD — средние накопленные просмотры за весь возраст статьи, не ежедневный
  поток. Для контроля возраста используются группы одного возраста,
  перцентили внутри месяца и регрессия с ковариатами.
- Выходные/праздники определяются по производственному календарю России
  с учётом рабочих суббот и перенесённых выходных. Одноразовые нерабочие дни
  указов 2020–2021 годов не считаются ежегодными праздниками.
- Корпуса пересекаются, поэтому согласование результатов между ними не
  является независимой репликацией. Покрытие широкого корпуса по одному из
  хабов ограничено.

## Независимость наблюдений и неопределённость

Статьи одного автора коррелируют между собой: основные интервалы получены
кластерным бутстрепом по авторам. В календарных проверках дополнительно
используется кластеризация по неделям. Для праздников альтернативная
перевыборка проводится целыми праздничными эпизодами и контрольными неделями.
Количество праздничных эпизодов широкого корпуса невелико, поэтому
интерпретация его интервалов особенно осторожная.

## Что показывают диагностические проверки

- Сравнение одного автора с самим собой исключает часть различий между
  авторами, но не различия в темах его публикаций и продвижении.
- Плотность публикаций до и после выхода статьи измеряется внутри выбранного
  корпуса, а не в персональной ленте читателя. Корреляции по агрегированным
  дням не эквивалентны корреляциям на уровне отдельных статей.
- Сила автора в описательном сравнении рассчитывается по другим статьям
  того же года методом leave-one-out. Это описание, а не признак для
  исторического прогноза: часть этих статей вышла позже рассматриваемой.
- Для прогнозных признаков используется только доступная на момент
  публикации информация. Поздние счётчики предыдущих статей автора не
  используются. `11_leakage_diagnostic.py` демонстрирует последствия
  нарушения этого правила.
- Проверки читаемости основаны на формальных свойствах текста, а не на
  оценке содержания. Разные индексы построены из одних и тех же длин слов и
  предложений, поэтому их согласованные результаты не независимы.

## Прогноз популярности и выбор времени

Режим A сравнивает прогноз популярности разных статей, B1 оценивает календарь
при фиксированном профиле, B2 сравнивает фактический слот каждой статьи с
её собственными допустимыми альтернативами. Для B2 используются только
поддержанные обучением слоты; календарные признаки альтернатив согласованы
с реальными датами. Модель и значения порогов выбираются на validation.

Ни один из режимов не наблюдает просмотры *той же статьи* в альтернативное
время. Следовательно, различие в рангах не оценивает причинный эффект
переноса статьи. Три шкалы B2 оставлены в отчёте как исследовательская
проверка чувствительности, а не способ подобрать самый выгодный результат.

## Дополнительная устойчивость

Отчёт `16_review_robustness.py` перепроверяет основной коэффициент выходных
при более грубых календарных контролях и при разбиении возраста на группы.
Он также исключает по одному праздничному эпизоду и сверяет квартильные доли
зрелых текстов с долями зрелых статей исходных корпусов. Подробные числа,
единицы сравнения и ограничения: [`docs/robustness.md`](robustness.md).

Статистическая значимость Манна — Уитни для праздничных статей оценивается на
уровне **статей**, не независимых праздничных эпизодов. Отдельно показан
эпизодический бутстреп по праздничным эпизодам и контрольным неделям; при
семи эпизодах в широком корпусе его интервал нельзя трактовать как точный.

## Основные контрольные файлы

- `tests/` и `experiments/catboost/tests/` — тесты обработки дат, текста,
  групп, статистики и прогнозных признаков.
- `data/input_manifest.json` — контрольные суммы входного среза.
- `experiments/catboost/configs/` — разбиения, функции потерь, правила отбора.
- `experiments/catboost/results/selected_policies.json` — выбор моделей,
  зафиксированный до вычисления итоговых метрик.
- `experiments/catboost/results/metrics/` — сравнения, интервалы,
  возрастные проверки и устойчивость.

## Проверки и границы утверждений сокращённой версии

- **Переходный снимок:** исходные HTTP-ответы и логи сбора 9–10 ноября не сохранены; можно проверить архивный состав, `postType` и критерии отбора, но нельзя достоверно реконструировать историческое поведение API.
- **Время публикации:** убедиться по коду, что `timePublished` интерпретируется в `Europe/Moscow` без двойного преобразования; не подменять это предположением о формате исходного timestamp.
- **Читаемость и AUC:** проверить в исходном скрипте, что «хит» — верхняя четверть по VPD, а `AUC = 0.593` оценена именно для отобранной по популярности текстовой выборки.
- **Прогноз популярности:** результаты валидации нельзя выдавать за независимую проверку на будущих статьях; оценка итогового периода имеет ретроспективный статус `audit_exposed`.
- **R²:** приращения объяснённого разброса `1.1–1.7` и `18–26` относятся к **процентным пунктам**, а не относительным процентам.
