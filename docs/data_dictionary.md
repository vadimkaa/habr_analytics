# Поля и расчётные показатели



Ключевые счётчики и производные поля, встречающиеся в JSONL/CSV пакета:

| Поле | Смысл |
|---|---|
| `readingCount` | Накопленные просмотры статьи — основная метрика «успеха» (`views`). Выбрана потому, что доступна в архивной выгрузке для обеих выборок и измеряется одинаково для всех статей |
| `reach` | Просмотры из ленты (фид) за отчётный период; в архивной выгрузке не для всех статей и не сопоставим по охвату, поэтому в анализ не входит |
| `readers` | Число читателей (уникальных пользователей) по данным Хабра; доступность и определение меняются, в анализ не входит |
| `score` | Рейтинг публикации: сумма голосов с весами (по умолчанию 1, с «Звездой»/«Старожилом» — 2, «Легенда» — 3, отрицательный голос −1); бывает отрицательным, лог-регрессия к нему неприменима |
| `favoritesCount` / `commentsCount` | Закладки и комментарии — вторичные исходы проверок выходных |
| `vpd` | `views / max(age_days, 1)` — накопленные просмотры за весь возраст статьи в днях; для статей младше суток знаменатель равен 1, в основном анализе используются зрелые статьи от 30 дней |
| `month_pct` | Перцентиль просмотров внутри месяца публикации (0–1]; основная метрика праздников |
| `dens24` / `dens24_fwd` | Число публикаций за предыдущие / следующие 24 часа; одновременные публикации конкурентами не считаются |
| `is_weekend` | Нерабочий день недели по производственному календарю (рабочие субботы — будни) |
| `is_translation` | Перевод чужой статьи; в замороженной выгрузке есть только у ИИ/МЛ, в широком корпусе поле отсутствует |
| `ttr_ru4` | Доля уникальных русских слов длиной ≥ 4; **падает с ростом длины текста** и в основном измеряет её — не использовать как меру разнообразия без оговорки |
| `mattr_ru4` | MATTR: средний TTR по скользящим окнам 500 русских слов (≥ 4 букв); устойчив к длине, для текста короче окна равен TTR |
| `long_word_share` | Доля русских слов (токенов из кириллических букв с возможным дефисом) длиной ≥ 10 символов среди всех русских слов в очищенном тексте |
| `code_char_share` | Доля символов содержимого блоков HTML `<pre>` от длины всего видимого текста до очистки; не число строк или блоков |
| `readingTime` | Время чтения из метаданных Хабра, не собственная оценка по числу слов |
| `log_vpd` | `log10(1+vpd)` в загружаемом корпусе; отдельно внутри проверки силы автора используется `strength_log = ln(max(vpd, 0.01))`, чтобы не смешивать эти преобразования |
| `formula_n` | Число распознанных контейнеров формул: `math/.katex/…`, `img.formula`, `img[data-tex]` |
